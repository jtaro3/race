# NEON LAP

Canvas 2Dで動く、ネオン調のカートレースゲームです。

## 遊び方

- `W` / `↑`: 加速
- `S` / `↓`: ブレーキ
- `A` / `←`: 左へ曲がる
- `D` / `→`: 右へ曲がる
- スマートフォンでは画面下のタッチボタンで操作できます。

5台のライバルと3周を競います。コース中央の緑色のブーストパッドを踏むと加速します。

## 起動

`index.html` をブラウザーで開くか、ローカルサーバーから配信してください。

```bash
npm install
npm run dev
```

## ファイル

- `index.html`: ゲーム画面とHUD
- `style.css`: レイアウトとビジュアル
- `game.js`: Canvas描画、操作、レース処理
